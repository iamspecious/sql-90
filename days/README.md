# Days

Each session gets one file: `day-NN.sql`, numbered by session, `day-01.sql` to `day-77.sql`. I create each file on the day. They aren't pre-generated.

If a session is more notes than queries (like day 1, which was setup), the notes go in `day-NN.md` instead, or alongside the `.sql` file.

Each file holds my own queries and my comments on them, including attempts that didn't work. Wrong attempts stay as written, with a comment underneath saying what went wrong, so the file shows how I got there and not just where I ended up.

A rough shape for each file:

```sql
-- Day NN, Week N: phase name
-- Date:
-- Goal for today:

-- Q1: what I'm trying to find out
-- my query here

-- Notes: what I noticed, what confused me
-- Confidence (1-5):
```
