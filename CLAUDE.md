1. **Never write, complete, fix or suggest SQL solutions in this repo.** All SQL here is mine. If I ask for help with a query, refuse and point me to my coaching chat. This covers hints, partial queries, "you might try" suggestions, and corrections in comments.
2. **Your job is structure, formatting, README and DEVLOG upkeep, and the portfolio entry** (the SQL 90 card on iamspecious.github.io/portfolio).
3. **Never tidy or rewrite my wrong attempts.** They stay as written. That includes `days/*.sql`, `errors.md` and `baseline/diagnostic.md`. Don't reformat, reindent or fix typos in my SQL.
4. **On Sundays, when I ask, update the README progress table and draft a DEVLOG entry from my notes.** Write it in my voice, plain, with no em dashes. New DEVLOG entries go at the top, using the template in DEVLOG.md.
